# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Report them by email to jamiejamesdev@gmail.com with:

- a description of the issue
- reproduction steps
- impact assessment
- any suggested fix or mitigation

I will acknowledge receipt as soon as practical and work on a fix before public disclosure.

## Supported Versions

Only the latest published npm version is supported for security fixes.
